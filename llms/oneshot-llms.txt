# OneShot

> OneShot (oneshot.ai) is an autonomous outbound sales prospecting platform from OneShot.ai
> Limited, a UK company based in Gerrards Cross, Buckinghamshire. It sources ideal-customer-
> profile leads, manages email and domain health, generates hyper-personalized email, LinkedIn
> and cold-call messaging with generative AI, and can run fully autonomous 24/7 outreach. It is
> delivered as a web application and a Chrome extension, and integrates with HubSpot, Salesforce,
> Apollo, Salesloft, Outreach, Gmail and Outlook.

## Important for agents

OneShot publishes **no developer API**. There is no OpenAPI or AsyncAPI document, no GraphQL
endpoint, no MCP server, no A2A agent card, no developer portal and no API reference on any
OneShot host. `api.oneshot.ai` is referenced by the web application's own JavaScript bundle but
does not resolve publicly. `app.oneshot.ai` and `security.oneshot.ai` answer HTTP 200 with a
single-page-application shell for *every* path, including `/openapi.json` and
`/.well-known/agent-card.json` — those 200s are not documents. Do not attempt to call a OneShot
API; integrate with OneShot through its product integrations with HubSpot, Salesforce, Apollo,
Salesloft and Outreach instead.
